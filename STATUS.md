# STATUS: deutsch-lehrerin

**Health**: 🟢 Healthy
**Last Updated**: 2026-05-02

## Context
The project is currently a functional prototype for a local German tutor. It focuses on removing the friction of cloud APIs and subscription models for language learning.

## Connections
- **Ollama/LM Studio**: Primary inference engines for the "Sovereign Brain."
- **Whisper/Piper**: Integration points for local voice-to-voice interaction.

## Capabilities
- **Voice-First Interaction**: Support for real-time conversation.
- **Proactive Tutoring**: Grammar correction and Dativ/Akkusativ explanations.
- **Everyday Sentences**: Database of 100+ high-frequency phrases for life in Germany.
- **Progress Tracking**: Local dashboard for monitoring learning sessions.

## Cadence
Active development. Currently in Phase 1 (Local Foundation), moving towards Phase 2 (Interactive Tutor) with integrated local STT/TTS models.
